Getting Started

Joining the Server

Add the server in Minecraft using the IP fitzsmp.cloudplay.fun and port 19000. Both Java and Bedrock editions are supported.

Bedrock Players

Bedrock players can connect using the same IP and port. Make sure to enter the port manually in the server address field.

Voice Chat

Once in the server, open the emote menu to get your voice chat link. See the Voice Chat wiki page for more details.

Voice Chat

Java Players

Java players use the Simple Voice Chat mod. Download it from Modrinth and install it in your mods folder. Voice chat will work automatically when you join.

Bedrock Players

Bedrock players use SimpleVoiceGeyser. When you join the server, open the emote menu and you'll get a link to open in your browser. Allow microphone access and you're good to go.

Troubleshooting

If voice chat isn't working, make sure you're using HTTPS and have allowed microphone access in your browser. Try refreshing the page if the connection drops.

Rules

General

Be respectful to other players. Griefing and stealing are allowed, but only with reason. Don't exploit bugs or use hacked clients.

Building

Keep the area around spawn clean.

Chat

Keep chat friendly. No spamming or excessive caps.
