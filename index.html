Getting Started

Java & Bedrock (PC)

Add the server using IP fitzsmp.cloudplay.fun and port 19000. Both editions are supported — on Bedrock, enter the port separately in the server address field.

Console Guides

Consoles can't add custom servers directly. Watch the relevant guide below to connect using a DNS workaround.

Voice Chat

Java Players

Download the Simple Voice Chat mod from Modrinth and install it in your mods folder. Voice chat will work automatically once you join.

Bedrock Players

Open the emote menu in-game and you'll receive a link. Open it in your browser, allow microphone access, and you're connected.

Troubleshooting

Make sure you're on HTTPS and microphone access is allowed in your browser. Refresh the page if the connection drops.

Rules

General

01Be respectful to other players.
02No hacked clients or exploiting bugs.
03Keep chat friendly — no spamming or excessive caps.

Raiding & PvP

World

06Keep the area around spawn clean.
Plugins

Geyser + Floodgate

Allows Bedrock players to join the Java server without a Java account.

Simple Voice Chat

Proximity voice chat. Java players use the mod, Bedrock players use the browser link.

BlueMap

Live 3D map of the server world, viewable in your browser via the sidebar link.

SkinsRestorer

Lets Bedrock players show their custom skins on the server.

ViaVersion + ViaBackwards

Allows older and newer Minecraft versions to connect.
